# Jacks

Internal recruitment SaaS frontend (mock data). TrendTrack-inspired dual-rail shell with light/dark themes.

## Scripts

```bash
npm install
npm run dev
npm run build
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Stack

Vite · React · TypeScript · Tailwind CSS · Recharts · Lucide · Framer Motion
